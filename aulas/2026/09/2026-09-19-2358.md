## ✏️ Corrections

[svg](https://github.com/Jessica-Franca/English_Study_History/blob/main/prompts/prompt_final_aula.md#%EF%B8%8F-corrections)

| **Original**                                                      | **Corrected**                                                             | **Explanation**                                                                                              |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `I have experience with create data pipelines.`                   | `I have experience creating data pipelines.`                              | Depois de `experience with`, o verbo fica em `-ing`. Também é natural dizer `I have experience creating...`. |
| `pipeline with update data`                                       | `pipeline to update data`                                                 | Para indicar finalidade, usar `to + verb`.                                                                   |
| `alter type, the type columns`                                    | `change column types`                                                     | Forma mais natural para “alterar tipos de colunas”.                                                          |
| `databases local`                                                 | `local database`                                                          | Em inglês, o adjetivo vem antes do substantivo.                                                              |
| `I create pipelines to on-premise and cloud.`                     | `I create pipelines for on-premises and cloud environments.`              | `for` funciona melhor neste contexto; `on-premises` descreve o ambiente.                                     |
| `my pipelines are being procedures`                               | `I use stored procedures for the ETL process.`                            | Pipeline e procedure não são exatamente a mesma coisa; a procedure pode fazer parte do processo ETL.         |
| `ETL is extract, transform, load.`                                | `ETL stands for Extract, Transform, and Load.`                            | `stands for` = significa / é a sigla de.                                                                     |
| `ELT is extract, load, and transforms.`                           | `ELT stands for Extract, Load, and Transform.`                            | Os nomes das etapas ficam na forma base: `Transform`, não `transforms`.                                      |
| `five years old`                                                  | `for about five years`                                                    | `old` é usado para idade. Para duração, usar `for + período`.                                                |
| `In my day, this is much common.`                                 | `In my daily work, I mostly work with ETL.`                               | `daily work` = trabalho no dia a dia; `mostly` = principalmente.                                             |
| `with create procedures`                                          | `I create stored procedures.`                                             | Após `with`, essa construção estava incorreta; a frase pode ser simplificada.                                |
| `I make upload data.`                                             | `I load data.`                                                            | `load data` é a expressão usada para carregar dados.                                                         |
| `archives`                                                        | `files`                                                                   | No contexto, a palavra correta para “arquivos” é `files`.                                                    |
| `I mainly use Databricks for creating pipelines with transforms.` | `I mainly use Databricks for creating pipelines that transform data.`     | `transform` funciona como verbo; `that transform data` deixa o objetivo claro.                               |
| `I need one extra medallion with silver, bronze and gold.`        | `I use the Medallion Architecture, with Bronze, Silver, and Gold layers.` | A estrutura correta é `Medallion Architecture` + `layers`.                                                   |
| `load date`                                                       | `load data`                                                               | `data` = dados; `date` = data/calendário.                                                                    |
| `brute files`                                                     | `raw files`                                                               | `raw` = bruto; `brute` não é o termo usado para dados brutos.                                                |
| `dirty bruto`                                                     | `raw data`                                                                | Para o conceito de dados ainda não tratados, `raw data` é a expressão adequada.                              |
| `the silver layer is data transformers`                           | `The Silver layer contains transformed and cleaned data.`                 | `transformed` é o particípio usado para “transformado”.                                                      |
| `fact data, data dimension, stable`                               | `fact tables, dimension tables`                                           | Os termos corretos são `fact table` e `dimension table`; `table` = tabela, não `stable`.                     |
| `I work much with ETL.`                                           | `I work a lot with ETL.` / `I mostly work with ETL.`                      | Para frequência, `a lot` ou `mostly` soa mais natural que `much` nesta frase.                                |
| `This Azure data factor.`                                         | `Azure Data Factory is used to load and move data.`                       | `Azure Data Factory` é o nome da ferramenta; a frase precisa de uma estrutura completa.                      |

## ⚠️ Recurring Mistakes

[svg](https://github.com/Jessica-Franca/English_Study_History/blob/main/prompts/prompt_final_aula.md#%EF%B8%8F-recurring-mistakes)

* **Present perfect / duração:** continua aparecendo dificuldade com estruturas como `for five years`. É um reforço do erro já existente de `since / for` e uso de present perfect.
* **Infinitivo vs gerúndio:** novamente apareceu `experience with create`; o correto é `experience with creating` ou `experience creating`.
* **Preposições:** exemplos como `pipelines to on-premise and cloud` mostram que as preposições ainda precisam de reforço.
* **Vocabulário básico:** palavras simples como `environment`, `files`, `load`, `approach`, `happens` e `reaches` ainda podem bloquear a compreensão.
* **Compreensão de perguntas:** `Which approach have you used in your experience?` não foi compreendida inicialmente.
* **Tradução direta do português:** apareceram estruturas como `make upload data`, `brute files`, `data transformers` e `stable`.
* **Escolha da forma da palavra:** dificuldade com `transform` × `transformed` e `transform` × `transforms`.
* **Vocabulário técnico específico:** houve necessidade de aprender a diferença entre `local environment`, `on-premises environment` e `cloud environment`.
