# Vocabulário geral

Palavras do dia a dia e de conversação. Não duplicar entradas. Se a palavra voltar em outra aula, só acrescente exemplo novo.

| Word / Expression | Meaning | Example | Aula | Contexto |
| ----------------- | ------- | ------- | ---- | -------- |
| currently | atualmente | I currently work with Power BI. | — | o que você faz agora |
| responsible for | responsável por | I was responsible for the sales dashboard. | — | cargo / tarefa |
| improve | melhorar | I want to improve my English. / We improved the report performance. | 2026-09-19 | inglês ou resultado de projeto |
| challenge | desafio | The main challenge was data quality. | — | o que estava difícil |
| biggest challenge | maior dificuldade | My biggest challenge is speaking. | 2026-09-19 | entrevista / autoavaliação |
| explain | explicar | I explained the KPI to the team. | — | falar para outra pessoa |
| usually | geralmente | I usually work with Power BI. | 2026-09-19 | rotina |
| last weekend | último fim de semana | Last weekend, I stayed at home. | 2026-09-19 | passado recente |
| stay at home | ficar em casa | I stayed at home this weekend. | 2026-09-19 | rotina / fim de semana |
| go out | sair | I didn't go out yesterday. | 2026-09-19 | sair de casa |
| spend time with | passar tempo com | I spend time with my son. | 2026-09-19 | família |
